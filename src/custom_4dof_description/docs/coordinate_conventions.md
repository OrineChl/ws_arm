# 坐标、零位与正方向

所有长度为米，角度为弧度，旋转遵循右手定则。

工程图坐标 D 的原点为 J1 中心轴与底座底面的交点；
+X_D 向图纸左，+Y_D 向图纸上，+Z_D 指向图纸内。
J1 的正轴为 +Y_D；J2、J3、J4 的正轴为 +Z_D。

ROS base_link 使用右手、Z 向上的 B 系，与 D 原点重合：

```
x_B = x_D
y_B = -z_D
z_B = y_D

       [1  0  0]
R_BD = [0  0 -1]
       [0  1  0]
```

这对应 +X_B=+X_D，+Y_B=-Z_D，+Z_B=+Y_D。
Xacro 直接在 B 系写入几何和关节原点，不再额外旋转 base_link，避免重复转换。
所有 joint origin 的 rpy 为零。URDF axis 在各关节局部坐标中定义：
joint1=(0,0,1)，joint2～joint4=(0,-1,0)。

工程图姿态即 q1=q2=q3=q4=0，各局部坐标系此时与 B 平行。
J2～J4 的正轴在零位看似“指向图纸内”，但并非固定的 world 轴：
它们随 J1 旋转改变在 world 中的方向。若 world 与 base_link 对齐，
则其方向为 (sin(q1), -cos(q1), 0)；前级俯仰关节因轴平行不改变这个方向。
本包没有创建 world，RViz 固定坐标系为 base_link。

| 原点 | 零位在 base_link 下的位置（m） |
| --- | --- |
| J1 / link1 | (0, 0, 0) |
| J2 / link2 | (0, 0, 0.161) |
| J3 / link3 | (0, 0, 0.352) |
| J4 / link4 | (0.172, 0, 0.352) |
| tool0 | (0.172, 0, 0.352) |
| tcp | (0.264, 0, 0.372) |

采用 base_link → link1 → link2 → link3 → link4 → tool0 → tcp 单链。
tool0 固定且与 link4 重合；tcp 相对 tool0 平移 (0.092,0,0.020)，旋转为零。
TCP 平移是 **provisional** 工程图估计，并非最终标定值；末端坐标方向也需在实物上确认。
夹爪张合电机不加入链。方盒/圆柱仅为可视化示意，碰撞外形未经过实物验证。
